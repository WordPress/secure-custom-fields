# Global Functions

## `acf_save_post_revision()`

This function will copy meta from a post to it's latest revision

* @type    function
* @date 26/09/2016
* @since ACF 5.4.0
* @param   $post_id (int)
* @return n/a

## `acf_get_post_latest_revision()`

This function will return the latest revision for a given post

* @type    function
* @date 25/06/2016
* @since ACF 5.3.8
* @param   $post_id (int)
* @return $post_id (int)
