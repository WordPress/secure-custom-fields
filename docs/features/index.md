# Features

This section details all features available in Secure Custom Fields.

## Core Features

- [Post Types](post-types.md) - Create and manage custom post types
- [Fields](fields.md) - Available field types and their usage
- [API](api.md) - Programmatic access and integration

## Feature Categories

1. **Content Management**
   - Custom post types
   - Custom taxonomies
   - Field groups

2. **Field Types**
   - Basic fields (text, textarea, etc.)
   - Advanced fields (repeater, flexible content)
   - Special fields (relationship, clone)

3. **Developer Tools**
   - API endpoints
   - Hooks and filters
   - Helper functions
