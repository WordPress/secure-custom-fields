# Using the Textarea Field

## Basic Setup
1. Create a new Field Group
2. Add a Textarea field
3. Configure options:
   - Set rows
   - Add placeholder
   - Configure limits
   - Set line handling

## Common Use Cases
1. Long Text Content
   - Descriptions
   - Biographies
   - Instructions
   - Notes

2. Content Management
   - Excerpts
   - Summaries
   - Meta descriptions
   - Comments

## Tips
- Set appropriate height
- Consider word limits
- Use clear placeholders
- Plan for formatting
