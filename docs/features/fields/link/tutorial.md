# Using the Link Field

## Basic Setup
1. Create a new Field Group
2. Add a Link field
3. Configure options:
   - Choose return format
   - Set default value
   - Configure display
   - Enable/disable features

## Common Use Cases
1. Navigation Elements
   - Menu links
   - Call-to-actions
   - Resource links

2. Content References
   - Related content
   - External resources
   - Document links

## Tips
- Validate URLs properly
- Consider link targets
- Use clear link text
- Check for broken links
