# Using the Separator Field

## Basic Setup
1. Create a new Field Group
2. Add a Separator field
3. Configure options:
   - Set label text
   - Add instructions
   - Style wrapper
   - Position field

## Common Use Cases
1. Content Organization
   - Section breaks
   - Field grouping
   - Visual hierarchy

2. Form Structure
   - Content sections
   - Logical breaks
   - Visual spacing

## Tips
- Use clear labels
- Keep consistent styling
- Consider spacing
- Group related fields
