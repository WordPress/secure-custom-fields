# Using the oEmbed Field

## Basic Setup

1. Create a new Field Group
2. Add an oEmbed field
3. Configure options:
   - Set width/height
   - Configure preview
   - Set display options
   - Choose providers

## Common Use Cases

1. Media Integration
   - Video embeds
   - Social media posts
   - Audio content

2. External Content
   - YouTube videos
   - Twitter posts
   - Spotify tracks

## Tips

- Check provider compatibility
- Consider responsive sizing
- Test embed previews
- Validate URLs properly
