# Using the Range Field

## Basic Setup

1. Create a new Field Group
2. Add a Range field
3. Configure options:
   - Set min/max values
   - Configure step size
   - Add prepend/append text
   - Set default value

## Common Use Cases

1. Numeric Ranges
   - Volume controls
   - Percentage settings
   - Scale selections

2. Visual Settings
   - Opacity levels
   - Size adjustments
   - Intensity controls

## Tips

- Set intuitive ranges
- Use clear min/max values
- Consider step granularity
- Add helpful labels
