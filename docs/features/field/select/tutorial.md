# Using the Select Field

## Basic Setup

1. Create a new Field Group
2. Add a Select field
3. Configure options:
   - Add choice options
   - Set default value
   - Configure UI settings
   - Enable/disable features

## Common Use Cases

1. Option Selection
   - Status choices
   - Category selection
   - Preference settings

2. Data Filtering
   - View options
   - Content filtering
   - Display settings

## Tips

- Use clear option labels
- Consider grouping options
- Enable search for long lists
- Set meaningful defaults
