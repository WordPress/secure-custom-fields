# Using the Image Field

## Basic Setup

1. Create a new Field Group
2. Add an Image field
3. Configure options:
   - Set preview size
   - Choose library type
   - Configure size limits
   - Set return format

## Common Use Cases

1. Content Images
   - Featured images
   - Article photos
   - Profile pictures

2. Design Elements
   - Background images
   - Logo uploads
   - Banner images

## Tips

- Set appropriate size limits
- Consider image dimensions
- Use meaningful preview sizes
- Plan for responsive display
