# Using the Gallery Field

## Basic Setup

1. Create a new Field Group
2. Add a Gallery field
3. Configure options:
   - Set image restrictions
   - Choose preview size
   - Configure min/max images
   - Set insert position

## Common Use Cases

1. Image Collections
   - Photo galleries
   - Product images
   - Portfolio displays

2. Media Management
   - Slideshows
   - Image grids
   - Media libraries

## Tips

- Set appropriate image limits
- Consider thumbnail sizes
- Enable easy reordering
- Optimize image sizes
